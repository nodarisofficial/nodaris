# Nodaris (NDRS)

A CPU-friendly proof-of-work cryptocurrency with a fixed 19,000,000 supply.

- Algorithm: Yespower (mineable on phones and PCs)
- Block time: 2 minutes
- Reward: 10 NDRS, halving every ~3.6 years
- Fair launch: no premine

Status: in testing, not launched yet.

Read the [Whitepaper](WHITEPAPER.md) for details.
